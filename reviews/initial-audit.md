# 初期監査 — 2026-10-25

## 結論

静的Webアプリ・端末保存・家計JSONバックアップ/復元・CSV出力・4人目の試算・資金不足表示は既存機能である。教育費準備額画面は独立した保存領域であり、家計キャッシュフローとは未接続。既存の動作を全面的に書き換える必要はない。

今回の独立再計算は、Pythonの現在価値法・資産保存則・入学日の算出で、元のJavaScriptを複製せず検証する。ソースと配布HTMLの**両方**を実行して照合する。AI間の多数決やモデルの自己申告を合格根拠にしない。

**Highの計算問題が3件再現したため、公開不可。** 開発・テスト可能な状態と、利用者の家計判断に使える計算精度を区別する。修正には要件・計算条件の確定と人による承認が必要であり、本変更では計算ロジックを変更していない。

## 検証した範囲

```bash
python -m unittest discover -s automation -p test_independent_finance.py -v
```

| テスト | 独立した検証方法 |
|---|---|
| 資産保存則48入力 | 現金・投資・損益・積立の移動が総額を生成しないことを代数式で検証。投資全損・負の現金・不足分を含む。 |
| 定額毎月ローン | 将来支払いの割引現在価値の総和から月額を逆算し、年次残高の保存則と照合。実装のPMT式を転記しない。 |
| 無利息+繰上返済 | 全返済額=元本、利息=0、繰上額の一度だけの計上。 |
| 学年境界 | 最初の入学日から学年を計算。4月1日/4月2日・閏日を含む月次在籍数を照合。 |
| 家計繰越 | 手取り月額×12+年間ボーナス、費目合計、前年度純金融資産から翌年度への保存則。 |
| 出生月の手当 | 第1子の1月/6月/12月末出生で翌月開始仮定の月数を照合。個別資格の確認とは別。 |
| 0〜4人/双子/将来出生 | 子ども別・年別・段階別の重複なし、年教育費合計、負の残高繰越。 |
| 不正入力 | 不正閏日・NaN・Infinity・4人目の生年月日不足で計算を拒否。 |

`finance_probe.cjs` は読み取り専用のNodeアダプター。テスト期待値はPython側で算出し、実装関数を呼んで期待値に転用しない。
