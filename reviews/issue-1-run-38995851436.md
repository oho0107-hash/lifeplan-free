# AIレビュー・自動開発レポート

## 要望
AIエージェントの自動開発テストです。

変更内容
ライフプランアプリの結果画面に、以下の注意書きがまだ存在しなければ追加してください。

「この試算は将来の参考値であり、実際の収入・支出・制度適用額を保証するものではありません。」

条件

* 既存の計算式、教育費、住宅ローン、年金などの計算ロジックは変更しない。
* 初期設定値や入力データの保存処理は変更しない。
* 要件検討と専門家レビューを実施する。
* コード修正後に既存の自動テストを実行する。
* 修正結果とレビュー結果をPull Requestで提出する。
* 本番公開は承認待ちとする。
