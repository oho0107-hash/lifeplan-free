# AIレビュー・自動開発レポート

## 要望
教育費の推計精度向上を目的に、実費調査AIと専門家レビューAIに調査を依頼します。

調査対象

* 開成中学校
* 市川中学校
* 渋谷教育学園幕張中学校
* 早稲田アカデミーの中学受験コース

調査条件

1. 学校・塾の公式サイトで確認できる最新年度の料金を使用する。
2. 入学金・授業料・施設費・教材費・制服代・通学費・季節講習・模試・受験料などを項目別に整理する。
3. 初年度と2年目以降の費用を区別する。
4. 未確認費用は0円とせず「未確認」と表示する。
5. 高額な学校の平均値を使って、必要以上に教育費を上振れさせない。
6. 金額には公式URL・対象年度・確認日を必ず付ける。
7. 学費と補助金を別々に集計する。
8. 子ども1人あたりの年間費用と、進学段階ごとの合計費用を比較できるようにする。

開発条件

* 現在の教育費計算式は勝手に変更しない。
* まず根拠付きの実費データと比較結果を作る。
* 既存の自動テストを実行する。
* 結果をPull Requestで提出し、本番反映は承認待ちにする。

## 調査専用モード：アプリ本体は変更なし
学校別の公式料金の証拠と未確認費目を提出します。教育費の標準金額には自動反映しません。
未確認費用は0円ではありません。料金の単純合計は学校・コース・対象年度が混ざるため行いません。
根拠付き料金が0件の場合は不完全な調査結果であり、費用推計の完了とはみなしません。
