# iPhoneからの継続運用

1. Codexでこのリポジトリを選び「育休中の収入計算をより正確にして」のように指示する。家庭の実収入・住所・生年月日・APIキーは公開Issueやコードへ入れない。
2. CodexはAGENTS.mdから役割・要件・反証・実装・テスト・監査・PRまで進める。工程ごとのファイル差替えは不要。レビュー結果で「実行済み」「未検証」「権限により未実行」を確認する。
3. 重要な計算・制度・金額・セキュリティ・権限変更は、根拠とテスト証拠のあるPRで承認する。Critical/Highや重大未検証の残るPRは公開しない。軽微変更も必須チェックを解除しない。
4. GitHub Issueも所有者からの要求入口として利用できる。既存Gemini Secret・利用枠・Actions権限がある場合に起動する。未設定や上限到達時は停止し、現在の公開アプリを維持する。秘密値はGitHub/クラウドの安全な設定画面で入力し、チャットには貼らない。
5. アプリの変更前に端末内の設定バックアップを保存し、復元はアプリの読込み機能を使う。公開後はiPhone Safariで入力・計算・保存復元を確認する。実家計バックアップをGitHubに添付しない。

初期設定やbranch protectionなどサービス側の権限が必要な場合だけ、担当が具体的な必要操作を案内する。APIに課金する契約は自動作成しない。今回のCI権限変更は承認後にマージし、それまでは本番へ反映されない。古いUPGRADE_iPHONE.mdのZIP差し替え作業を日々の運用として繰り返す必要はない。
